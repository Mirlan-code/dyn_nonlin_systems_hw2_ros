## Описание робота и его структуры
Сделал подобие экскаватора без гусениц и без поворотной стрелы вбок

Соответственно, имеется 4 шарнира:
1. Вращательный continuous - основание
2. Вращательный revolute - первая часть стрелы
3. Вращательный revolute - вторая часть стрелы
4. Вращательный revolute - ковш

Основание вращается относительно оси Z в базовой СК. Остальные шарниры в плоскости yz.
Шаринры соединены звеньями, более детально конфигурация описана в urdf tree

urdf tree находится в ./excavator.pdf


## Описание движения робота
Идея - экскаватор копает землю, то есть необходимо:
1. вынести руку вперёд (стрела наклоняется вперёд, рукоять и ковш разгибаются)
2. опустить стрелу к земле
3. зачерпнуть землю
4. поднять стрелу
5. повернуться на 90 градусов
6. высыпать землю
7. вернуться в исходное положение

controller.py из себя представляет основные позы и перемещение между ними. Положение публикуется в joint_states и представляют с собой алгоритм, основанный на времени:
1. t = t_curr - t_start
2. curr_segment = (t / SEGMENT_TIME) % total_segments
3. ratio = (t % SEGMENT_TIME) / SEGMENT_TIME (какую часть задачи перехода мы уже сделали, скорость равномерная)
4. pose = curr_pose + diff(curr_pose, next_pose) * ratio

Запуск:

``ros2 launch excavator display.launch.py gui:=false``
